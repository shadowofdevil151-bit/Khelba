## ১. ওয়েব ডিজাইনের মৌলিক ধারণা (Basics of Web Design)

**📌 মূল পরিভাষা (Key Terms):**
*   **ওয়েবসাইট (Website):** একই ডোমেইন নামের অধীনে থাকা একাধিক ওয়েব পেজের সমষ্টি।
*   **ওয়েব পেজ (Web Page):** ওয়েবসাইটের প্রতিটি পৃথক পৃষ্ঠা। এটি মূলত একটি HTML ডকুমেন্ট।
*   **হোম পেজ (Home Page):** ওয়েবসাইটে প্রবেশের প্রথম পেজ (সাধারণত `index.html`)।
*   **ওয়েব ব্রাউজার (Web Browser):** ওয়েব পেজ দেখার সফটওয়্যার (Chrome, Firefox, Edge)।
*   **ওয়েব সার্ভার (Web Server):** যে কম্পিউটারে ওয়েবসাইটের ফাইল সংরক্ষিত থাকে এবং ব্রাউজারের রিকোয়েস্টে তা পাঠায়।
*   **URL (Uniform Resource Locator):** ইন্টারনেটে ওয়েবসাইটের নির্দিষ্ট ঠিকানা (যেমন: `https://www.google.com`)।

**📊 স্ট্যাটিক বনাম ডাইনামিক ওয়েবসাইট:**
| স্ট্যাটিক ওয়েবসাইট (Static) | ডাইনামিক ওয়েবসাইট (Dynamic) |
| :--- | :--- |
| শুধু HTML, CSS দিয়ে তৈরি। | HTML, CSS এর পাশাপাশি PHP, Python, Database থাকে। |
| কন্টেন্ট পরিবর্তন করতে কোড পরিবর্তন করতে হয়। | অ্যাডমিন প্যানেল থেকে সহজেই কন্টেন্ট পরিবর্তন করা যায়। |
| ব্যবহারকারীর ইনপুট অনুযায়ী পরিবর্তন হয় না। | ব্যবহারকারীর ইনপুট/লগইন অনুযায়ী পরিবর্তিত হয় (যেমন: Facebook)। |

## ২. HTML এর ধারণা ও গঠন (Concept and Structure of HTML)

**📌 HTML কী?**
HTML এর পূর্ণরূপ হলো **HyperText Markup Language**। এটি একটি মার্কআপ ল্যাঙ্গুয়েজ, প্রোগ্রামিং ল্যাঙ্গুয়েজ নয়। এটি ওয়েব পেজের কাঠামো (Structure) তৈরি করে।

**🔄 HTML ট্যাগ কীভাবে কাজ করে? (How Tags Work)**
ট্যাগ হলো `<` ও `>` চিহ্নের ভেতরে লেখা নির্দেশনা। HTML-এ দুই ধরনের ট্যাগ আছে:
1.  **কন্টেইনার ট্যাগ (Container Tag):** শুরু এবং শেষ ট্যাগ থাকে। ভেতরে কন্টেন্ট থাকে। যেমন: `<p> এটি প্যারাগ্রাফ </p>`।
2.  **এমপ্টি ট্যাগ (Empty Tag):** শেষ ট্যাগ নেই, একা কাজ করে। যেমন: `<br>` (লাইন ব্রেক), `<hr>` (হরাইজন্টাল লাইন), `<img>` (ছবি)।

**🔑 অ্যাট্রিবিউট (Attribute):** ট্যাগের ভেতরে অতিরিক্ত তথ্য দেওয়ার জন্য ব্যবহৃত হয়। গঠন: `<tag attribute="value">` (যেমন: `<body bgcolor="red">`)।

**🔄 HTML ডকুমেন্টের মৌলিক কাঠামো (Basic Structure):**
```html
<!DOCTYPE html>
<html>
<head>
    <title>আমার প্রথম ওয়েব পেজ</title>
</head>
<body>
    <h1>স্বাগতম!</h1>
    <p>এটি একটি প্যারাগ্রাফ।</p>
</body>
</html>
```

### HTML ডকুমেন্টের অংশ
`<!DOCTYPE html>`: ব্রাউজারকে জানায় এটি HTML5 ডকুমেন্ট।

`<html>`: সম্পূর্ণ ডকুমেন্টের রুট (Root) ট্যাগ।

`<head>`: মেটাডেটা (টাইটেল, স্টাইল) রাখার জায়গা।

`<title>`: ব্রাউজারের ট্যাবে যে নামটি দেখাবে।

`<body>`: ওয়েব পেজে যা কিছু দৃশ্যমান হবে, সবকিছু এখানে থাকে।

## ৩. HTML ট্যাগ ও বেসিক ফরম্যাটিং

| ট্যাগ | কাজ | উদাহরণ |
| :--- | :--- | :--- |
| `<h1>`–`<h6>` | শিরোনাম তৈরি করে (`h1` সবচেয়ে বড়)। | `<h1>Heading</h1>` |
| `<p>` | প্যারাগ্রাফ তৈরি করে। | `<p>Text</p>` |
| `<br>`, `<hr>` | লাইন ভাঙে বা অনুভূমিক রেখা তৈরি করে। | `<br>`, `<hr>` |
| `<b>`, `<i>`, `<u>` | লেখা বোল্ড, ইটালিক বা আন্ডারলাইন করে। | `<b>Bold</b>` |
| `<sup>`, `<sub>` | সুপারস্ক্রিপ্ট ও সাবস্ক্রিপ্ট তৈরি করে। | `a<sup>2</sup>`, `H<sub>2</sub>O` |
| `<center>`, `<font>`, `<marquee>` | পুরোনো HTML-এ বিন্যাস ও চলমান লেখা নির্ধারণে ব্যবহৃত হতো। | আধুনিক পেজে CSS ব্যবহার করা হয়। |

## ৪. লিস্ট তৈরি করা
### আন-অর্ডার্ড লিস্ট
বুলেট পয়েন্টের তালিকা তৈরি করে।

```html
<ul>
    <li>আম</li>
    <li>জাম</li>
    <li>কাঁঠাল</li>
</ul>
```

`type` অ্যাট্রিবিউটের মান: `disc` (ডিফল্ট), `circle` বা `square`।

### অর্ডার্ড লিস্ট
সংখ্যা বা অক্ষরের ক্রমে তালিকা তৈরি করে।

```html
<ol>
    <li>প্রথম</li>
    <li>দ্বিতীয়</li>
    <li>তৃতীয়</li>
</ol>
```

`type`-এর মান হতে পারে `1`, `A`, `a`, `I` বা `i`। `start="5"` দিলে তালিকা ৫ থেকে শুরু হয়।

## ৫. হাইপারলিংক ও ছবি যোগ করা
### হাইপারলিংক
`<a>` ট্যাগ এক পেজ থেকে অন্য পেজ বা ওয়েবসাইটে যাওয়ার লিংক তৈরি করে।

```html
<a href="https://www.google.com">গুগলে যান</a>
```

নতুন ট্যাবে খুলতে `target="_blank"` ব্যবহার করা হয়।

### ছবি
`<img>` একটি এমপ্টি ট্যাগ।

```html
<img src="image.jpg" alt="একটি ছবি" width="200" height="150">
```

*   `src`: ছবির ফাইল পাথ বা URL।
*   `alt`: ছবি লোড না হলে বিকল্প টেক্সট।
*   `width` / `height`: ছবির প্রস্থ ও উচ্চতা।

## ৬. টেবিল তৈরি করা
HTML টেবিলে ব্যবহৃত প্রধান ট্যাগ:

*   `<table>`: টেবিলের কাঠামো।
*   `<tr>`: সারি।
*   `<th>`: শিরোনাম সেল।
*   `<td>`: সাধারণ ডেটা সেল।

**➡️ সাধারণ টেবিলের উদাহরণ:**

```html
<table border="1" cellspacing="0" cellpadding="5">
    <caption>শিক্ষার্থীদের তালিকা</caption>
    <tr>
        <th>নাম</th>
        <th>রোল</th>
        <th>শ্রেণি</th>
    </tr>
    <tr>
        <td>রহিম</td>
        <td>০১</td>
        <td>একাদশ</td>
    </tr>
    <tr>
        <td>করিম</td>
        <td>০২</td>
        <td>দ্বাদশ</td>
    </tr>
</table>
```

**🔑 গুরুত্বপূর্ণ অ্যাট্রিবিউট:**

*   `border="1"`: টেবিলের চারপাশে বর্ডার দেয়।
*   `cellspacing="0"`: সেলের মধ্যবর্তী ফাঁকা জায়গা নিয়ন্ত্রণ করে।
*   `cellpadding="5"`: সেলের ভেতরে ফাঁকা জায়গা তৈরি করে।
*   `colspan="2"`: ২টি কলাম জুড়ে একটি সেল তৈরি করে।
*   `rowspan="2"`: ২টি সারি জুড়ে একটি সেল তৈরি করে।

**➡️ `colspan` ও `rowspan`-এর উদাহরণ:**

```html
<table border="1">
    <tr>
        <td colspan="2">এই ঘরটি ২টি কলাম জুড়ে আছে</td>
    </tr>
    <tr>
        <td>ঘর ১</td>
        <td>ঘর ২</td>
    </tr>
    <tr>
        <td rowspan="2">এই ঘরটি ২টি সারি জুড়ে আছে</td>
        <td>ঘর ৩</td>
    </tr>
    <tr>
        <td>ঘর ৪</td>
    </tr>
</table>
```

## ৭. ওয়েবসাইট প্রকাশ
ওয়েবসাইট তৈরি করার পর তা ইন্টারনেটে সবার জন্য উন্মুক্ত করার প্রক্রিয়াকে পাবলিশিং বলে।
**প্রকাশের ধাপ:**
1.  ডোমেইন নাম নিবন্ধন করা।
2.  ওয়েব হোস্টিং নেওয়া।
3.  FTP বা কন্ট্রোল প্যানেল দিয়ে ফাইল আপলোড করা।
4.  DNS-এ ডোমেইনকে হোস্টিং সার্ভারের সঙ্গে যুক্ত করা।

## ❓ সম্ভাব্য প্রশ্নোত্তর

### MCQ — এক নজরে
1. **HTML-এর পূর্ণরূপ কী?** — HyperText Markup Language।
2. **এমপ্টি ট্যাগের উদাহরণ কী?** — `<br>`, `<hr>`, `<img>`।
3. **টেবিলের সারির ট্যাগ কোনটি?** — `<tr>`।
4. **টেবিলের শিরোনাম সেলের ট্যাগ কোনটি?** — `<th>`।
5. **একাধিক কলাম বা সারি যুক্ত করতে কোন অ্যাট্রিবিউট লাগে?** — `colspan` বা `rowspan`।
6. **ব্রাউজার-ট্যাবের শিরোনাম কোন ট্যাগে থাকে?** — `<title>`।
7. **ছবি যোগ করার ট্যাগ কোনটি?** — `<img>`।

### CQ — সৃজনশীল প্রশ্নের উত্তর
**প্রশ্ন: একটি ওয়েব পেজের মৌলিক কাঠামো HTML-এ দেখাও।**

```html
<!DOCTYPE html>
<html>
<head>
    <title>আমার ওয়েবসাইট</title>
</head>
<body>
    <h1>শিরোনাম</h1>
    <p>এটি একটি প্যারাগ্রাফ।</p>
</body>
</html>
```

**প্রশ্ন: `colspan` ও `rowspan`-এর পার্থক্য কী?**  
**উত্তর:** `colspan` একই সারির একাধিক কলাম যুক্ত করে; `rowspan` একই কলামের একাধিক সারি যুক্ত করে।

**প্রশ্ন: তিনটি ফলসহ স্কয়ার বুলেটের আন-অর্ডার্ড লিস্ট তৈরি কর।**

```html
<ul type="square">
    <li>আম</li>
    <li>জাম</li>
    <li>কাঁঠাল</li>
</ul>
```

**প্রশ্ন: HTML টেবিলের ন্যূনতম কাঠামোর ট্যাগগুলো কী?**  
**উত্তর:** `<table>`, `<tr>` ও `<td>`।

**প্রশ্ন: হাইপারলিংক কী? নতুন ট্যাবে খুলতে কী ব্যবহার করতে হয়?**  
**উত্তর:** ক্লিক করে অন্য পেজে যাওয়ার লিংককে হাইপারলিংক বলে। `<a>` ট্যাগে `target="_blank"` দিলে লিংক নতুন ট্যাবে খোলে।
