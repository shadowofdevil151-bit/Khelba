## ১. প্রোগ্রামিং এর মৌলিক ধারণা (Basic Concepts of Programming)

**📌 প্রোগ্রাম (Program):** নির্দিষ্ট কোনো সমস্যা সমাধান করার জন্য কম্পিউটারকে ধাপে ধাপে যে নির্দেশনা (Instruction) দেওয়া হয়, তাকে প্রোগ্রাম বলে। এই নির্দেশনার সমষ্টিকে সফটওয়্যারও বলা হয়।
**📌 প্রোগ্রামিং ভাষা (Programming Language):** কম্পিউটারের সাথে যোগাযোগ করার জন্য বা কম্পিউটারকে নির্দেশ দেওয়ার জন্য যে ভাষা (Language) ব্যবহার করা হয়, তাকে প্রোগ্রামিং ভাষা বলে।

**🔄 ভাষার প্রজন্ম অনুযায়ী শ্রেণিবিভাগ (Generations of Languages):**
1.  **প্রথম প্রজন্ম (1GL) - মেশিন ভাষা (Machine Language):** শুধু 0 এবং 1। কম্পিউটার সরাসরি বোঝে, কিন্তু মানুষের জন্য লেখা কঠিন।
2.  **দ্বিতীয় প্রজন্ম (2GL) - অ্যাসেম্বলি ভাষা (Assembly Language):** মেশিন ভাষার সংক্ষিপ্ত রূপ (যেমন: ADD, SUB)। এখানে Translator হিসেবে **Assembler** ব্যবহার হয়।
3.  **তৃতীয় প্রজন্ম (3GL) - উচ্চস্তরের ভাষা (High-Level Language):** মানুষের বোঝার উপযোগী (C, C++, Java, Python)। এখানে Translator হিসেবে **Compiler** বা **Interpreter** ব্যবহার হয়।
4.  **চতুর্থ প্রজন্ম (4GL):** ডেটাবেজ ও রিপোর্ট জেনারেট করার জন্য ব্যবহৃত (SQL, Oracle)।

**📊 Translator (অনুবাদক) প্রোগ্রামসমূহ:**
| Translator | কাজ (Function) |
| :--- | :--- |
| **Assembler** | অ্যাসেম্বলি ভাষাকে মেশিন ভাষায় রূপান্তর করে। |
| **Compiler** | সম্পূর্ণ প্রোগ্রামকে একসাথে মেশিন ভাষায় রূপান্তর করে এবং Error থাকলে পুরো প্রোগ্রামের Error একসাথে দেখায়। (যেমন: C, C++)। |
| **Interpreter** | লাইন বাই লাইন (Line by line) কোড রূপান্তর করে এবং চালায়। Error পেলে সাথে সাথে থেমে যায়। (যেমন: Python, JavaScript)। |

## ২. প্রোগ্রাম তৈরির ধাপ (Program Development Steps)

যেকোনো প্রোগ্রাম লেখার আগে ২টি জিনিস মাথায় রাখতে হয়: **অ্যালগরিদম** এবং **ফ্লোচার্ট**। HSC-তে এখান থেকে CQ আসে।

**১. অ্যালগরিদম (Algorithm):** কোনো সমস্যা সমাধানের ধাপে ধাপে বর্ণনা, যা সাধারণ ভাষায় (English/Bengali) লেখা হয়। এটি একটি Text-based সমাধান।
*   *উদাহরণ (দুটি সংখ্যার যোগফল):*
    1. শুরু করো।
    2. A এবং B এর মান ইনপুট নাও।
    3. Sum = A + B হিসাব করো।
    4. Sum প্রিন্ট করো।
    5. শেষ করো।

**২. ফ্লোচার্ট (Flowchart):** অ্যালগরিদমকে যখন বিভিন্ন জ্যামিতিক চিহ্ন (Symbols) দিয়ে ছবির মাধ্যমে প্রকাশ করা হয়, তাকে ফ্লোচার্ট বলে।
**🔑 ফ্লোচার্টের প্রতীকসমূহ:**
| প্রতীক (Shape) | নাম (Name) | কাজ (Function) |
| :--- | :--- | :--- |
| **Oval (ডিম্বাকৃতি)** | Start/End | প্রোগ্রাম শুরু ও শেষ বোঝায়। |
| **Parallelogram (সামান্তরিক)** | Input/Output | ডেটা ইনপুট ও আউটপুট বোঝায়। |
| **Rectangle (আয়তক্ষেত্র)** | Process | গাণিতিক হিসাব বা প্রসেসিং বোঝায়। |
| **Diamond (রম্বস)** | Decision | শর্ত (Condition) পরীক্ষা করে (হ্যাঁ/না)। |
| **Arrow (তীরচিহ্ন)** | Flow Line | ডেটার প্রবাহের দিক বোঝায়। |

## ৩. সি (C) ভাষার পরিচিতি ও গঠন (C Language Basics)

**📌 সি ভাষার জনক:** ডেনিস রিচি (Dennis Ritchie), ১৯৭২ সালে বেল ল্যাবরেটরিতে।
**🔑 সি ভাষার বৈশিষ্ট্য:** এটি একটি Mid-level ভাষা। এটি দ্রুত কাজ করে এবং হার্ডওয়্যারের কাছাকাছি কাজ করতে পারে।

**🔄 সি প্রোগ্রামের সাধারণ গঠন (Structure of a C Program):**
প্রতিটি C প্রোগ্রামে কিছু নির্দিষ্ট অংশ থাকে:
```c
#include <stdio.h>  // 1. Preprocessor Directive (হেডার ফাইল)
int main() {        // 2. Main Function (প্রোগ্রামের প্রবেশদ্বার)
    printf("Hello World"); // 3. Statement (কাজ)
    return 0;       // 4. Return Statement (সফলভাবে শেষ)
}
```

### C প্রোগ্রামের অংশ
#include <stdio.h>: এটি Standard Input Output Header File। printf এবং scanf ব্যবহারের জন্য এটি লাগে।

int main(): এখান থেকেই প্রোগ্রামের কাজ শুরু হয়।

; (Semicolon): C ভাষায় প্রতিটি Statement এর শেষে সেমিকোলন দিতে হয়।

## ৪. ভেরিয়েবল, ডেটা টাইপ ও কীওয়ার্ড
📌 ভেরিয়েবল (Variable): যে পাত্রে বা মেমোরি লোকেশনে ডেটা সংরক্ষণ করা হয় এবং যার মান পরিবর্তনশীল। (যেমন: int a = 5;)

**📊 ডেটা টাইপ:**

| ডেটা টাইপ | অর্থ | মেমোরি | Format Specifier | উদাহরণ |
| :--- | :--- | :--- | :--- | :--- |
| `int` | পূর্ণসংখ্যা | 2 বা 4 বাইট | `%d` | `int age = 20;` |
| `float` | দশমিক সংখ্যা | 4 বাইট | `%f` | `float price = 99.5;` |
| `char` | একটি অক্ষর | 1 বাইট | `%c` | `char grade = 'A';` |
| `double` | অধিক নির্ভুলতার দশমিক সংখ্যা | 8 বাইট | `%lf` | `double pi = 3.1416;` |
| `void` | কোনো মান নেই | প্রযোজ্য নয় | — | ফাংশন মান ফেরত না দিলে ব্যবহৃত হয়। |
🔑 কীওয়ার্ড (Keywords): C ভাষায় ৩২টি রিজার্ভড ওয়ার্ড আছে যেগুলো ভেরিয়েবলের নাম হিসেবে ব্যবহার করা যায় না। (যেমন: int, float, if, else, for, while, return, break, continue, switch, case ইত্যাদি)।
🔑 ধ্রুবক (Constant): যার মান প্রোগ্রাম চলাকালীন পরিবর্তন হয় না। (যেমন: const float PI = 3.14159;)

## ৫. ইনপুট/আউটপুট ও অপারেটর
১. printf(): আউটপুট দেখানোর জন্য।

```c
printf("Hello"); // সাধারণ আউটপুট
printf("Age: %d", age); // ভেরিয়েবলের মান দেখানো
```

২. scanf(): ইউজারের কাছ থেকে ইনপুট নেওয়ার জন্য।

```c
scanf("%d", &age); // & চিহ্নটি ভেরিয়েবলের মেমোরি অ্যাড্রেস বোঝায়
```

⚠️ সতর্কতা: printf-এ & লাগে না, কিন্তু scanf-এ & (Ampersand) অবশ্যই লাগবে (String/Array ছাড়া)।

**📊 অপারেটরসমূহ:**

| ধরন | চিহ্ন | কাজ |
| :--- | :--- | :--- |
| গাণিতিক | `+`, `-`, `*`, `/`, `%` | যোগ, বিয়োগ, গুণ, ভাগ ও ভাগশেষ |
| তুলনামূলক | `>`, `<`, `>=`, `<=`, `==`, `!=` | তুলনা করে |
| লজিক্যাল | `&&`, `||`, `!` | একাধিক শর্ত যুক্ত করে |
| ইনক্রিমেন্ট/ডিক্রিমেন্ট | `++`, `--` | ১ বাড়ায় বা কমায় |

## ৬. কন্ডিশনাল স্টেটমেন্ট
প্রোগ্রামে সিদ্ধান্ত নেওয়ার জন্য শর্ত ব্যবহার করা হয়। "যদি এটা হয়, তবে এটা করো"।

১. if-else স্টেটমেন্ট:

```c
if (condition) {
    // শর্ত সত্য হলে এই কোড চলবে
} else {
    // শর্ত মিথ্যা হলে এই কোড চলবে
}
```

উদাহরণ (পাস/ফেল):

```c
int marks = 40;
if (marks >= 33) {
    printf("Pass");
} else {
    printf("Fail");
}
```

২. else if ল্যাডার (একাধিক শর্ত):

```c
int marks = 80;
if (marks >= 80) {
    printf("A+");
} else if (marks >= 70) {
    printf("A");
} else {
    printf("Fail");
}
```

৩. switch-case স্টেটমেন্ট: একাধিক নির্দিষ্ট মানের (যেমন: ১, ২, ৩) জন্য কাজ করে।

```c
int day = 2;
switch(day) {
    case 1: printf("Saturday"); break;
    case 2: printf("Sunday"); break;
    default: printf("Invalid");
}
```

🔑 break: প্রতিটি case এর শেষে break দিতে হয়, নাহলে এটি পরবর্তী case-ও চালিয়ে দেয়।

## ৭. লুপ স্টেটমেন্ট
একই কাজ বারবার করার জন্য লুপ ব্যবহার করা হয়।

১. for লুপ: যখন পুনরাবৃত্তির সংখ্যা আগে থেকেই জানা থাকে।

```c
for (initialization; condition; increment) {
    // এই কোড বারবার চলবে
}
```

উদাহরণ (১ থেকে ৫ পর্যন্ত প্রিন্ট):

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// আউটপুট: 1 2 3 4 5
```

২. while লুপ: যখন শর্ত সত্য থাকে ততক্ষণ চলবে। পুনরাবৃত্তির সংখ্যা আগে থেকে জানা না থাকলে ব্যবহার হয়।

```c
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++; // এটি না দিলে Infinite Loop হবে!
}
```

৩. do-while লুপ: এটি অন্তত একবার (১ বার) কোড চালাবে, তারপর শর্ত পরীক্ষা করবে।

```c
int i = 10;
do {
    printf("Hello");
} while (i < 5);
// শর্ত মিথ্যা হলেও একবার "Hello" প্রিন্ট হবে।
```

**📊 `while` বনাম `do-while`:**

| `while` লুপ | `do-while` লুপ |
| :--- | :--- |
| প্রথমে শর্ত পরীক্ষা করে, পরে কোড চালায়। | প্রথমে কোড চালায়, পরে শর্ত পরীক্ষা করে। |
| শর্ত মিথ্যা হলে কোড চলে না। | শর্ত মিথ্যা হলেও অন্তত একবার চলে। |

## ৮. অ্যারে ও ফাংশন
**🔑 অ্যারে (Array):** একই ধরনের একাধিক ডেটা একসঙ্গে সংরক্ষণ করে।

**১-ডি অ্যারের উদাহরণ:**
```c
int numbers[5] = {10, 20, 30, 40, 50};
```

**অ্যারের উপাদান প্রিন্ট করা:**
```c
for (int i = 0; i < 5; i++) {
    printf("%d\n", numbers[i]);
}
```

**🔑 ফাংশন (Function):** বড় প্রোগ্রামকে ছোট, পুনর্ব্যবহারযোগ্য অংশে ভাগ করে।

**সিনট্যাক্স:**
```c
return_type function_name(parameters) {
    // কাজ
    return value;
}
```

**উদাহরণ:**
```c
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 3);
    printf("%d", result);
    return 0;
}
```

### CQ — সৃজনশীল প্রশ্নের উত্তর
**প্রশ্ন: অ্যালগরিদম ও ফ্লোচার্টের পার্থক্য কী?**  
**উত্তর:** অ্যালগরিদমে সমস্যা সমাধানের ধাপ সাধারণ ভাষায় লেখা হয়; ফ্লোচার্টে জ্যামিতিক প্রতীকের মাধ্যমে সেই ধাপগুলো দেখানো হয়।

**প্রশ্ন: `for` ও `while` লুপের পার্থক্য লেখ।**  
**উত্তর:** পুনরাবৃত্তির সংখ্যা আগে থেকে জানা থাকলে সাধারণত `for` ব্যবহার করা হয়। `while` শর্ত সত্য থাকা পর্যন্ত চলে।

**প্রশ্ন: `printf()` ও `scanf()`-এর পার্থক্য কী?**  
**উত্তর:** `printf()` আউটপুট দেখায়; `scanf()` ইনপুট নেয়। `scanf()`-এ সাধারণ ভেরিয়েবলের ঠিকানা দিতে `&` ব্যবহৃত হয়।

**প্রশ্ন: ১ থেকে ১০০ পর্যন্ত সংখ্যার যোগফল বের করার C প্রোগ্রাম লেখ।**

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum += i;
    }
    printf("Sum = %d", sum);
    return 0;
}
```

**প্রশ্ন: `switch-case`-এ `break` না দিলে কী হয়?**  
**উত্তর:** `break` না থাকলে পরবর্তী `case`-এর কোডও চলতে পারে; একে fall-through বলে।
