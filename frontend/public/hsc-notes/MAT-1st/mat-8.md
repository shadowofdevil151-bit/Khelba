## 📌 ১. ফাংশনের বেসিক (Function Basics)

**ফাংশন (Function):**如果一个 সেটের প্রতিটি উপাদানকে অন্য একটি সেটের ঠিক একটি উপাদানের সাথে সম্পর্কযুক্ত করা হয়, তবে সেই সম্পর্ককে ফাংশন বলে।
*   **ডোমেইন (Domain):** ইনপুট মানের সেট (সাধারণত $x$)।
*   **রেঞ্জ (Range):** আউটপুট মানের সেট (সাধারণত $y$)।
*   **কো-ডোমেইন (Co-domain):** সম্ভাব্য আউটপুটের সেট।

### 🔄 ফাংশনের প্রকারভেদ (Types of Functions)
| ফাংশনের নাম | বৈশিষ্ট্য / গাণিতিক শর্ত | উদাহরণ |
| :--- | :--- | :--- |
| **এক-এক (One-One / Injective)** | ডোমেইনের ভিন্ন ভিন্ন উপাদানের ছবি ভিন্ন ভিন্ন হবে। $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$ | $f(x) = 2x + 1$ |
| **সার্বিক (Onto / Surjective)** | রেঞ্জ = কো-ডোমেইন। | $f: \mathbb{R} \to \mathbb{R}$, $f(x) = x^3$ |
| **অভেদক (Identity)** | প্রতিটি উপাদান নিজের সাথে ম্যাপ হয়। $f(x) = x$ | $f(x) = x$ |
| **ধ্রুবক (Constant)** | ডোমেইনের সব উপাদানের জন্য আউটপুট একই। $f(x) = c$ | $f(x) = 5$ |

> 💡 **Exam Tip:** যদি $f$ ফাংশনটি এক-এক এবং সার্বিক (Bijective) হয়, তবে এর **বিপরীত ফাংশন (Inverse Function)** $f^{-1}$ বিদ্যমান থাকবে।

## 🔄 ২. বিপরীত ফাংশন (Inverse Function)

**সংজ্ঞা:** $f: A \to B$ যদি এক-এক এবং সার্বিক ফাংশন হয়, তবে $f^{-1}: B \to A$ কে $f$ এর বিপরীত ফাংশন বলে।
*   **শর্ত:** $f(x) = y \iff f^{-1}(y) = x$
*   **ধর্ম:** $f(f^{-1}(x)) = x$ এবং $f^{-1}(f(x)) = x$

### 🔹 বিপরীত ফাংশন নির্ণয়ের ধাপ
১. $y = f(x)$ ধরি।
২. $x$ কে $y$ এর মাধ্যমে প্রকাশ করি।
৩. $x$ এর জায়গায় $y$ এবং $y$ এর জায়গায় $x$ বসাই। ফলে $f^{-1}(x)$ পাওয়া যাবে।

### 🔹 গ্রাফের সাহায্যে বিপরীত ফাংশন
কোনো ফাংশনের গ্রাফকে $y = x$ রেখার সাপেক্ষে প্রতিফলিত (Reflection) করলে বিপরীত ফাংশনের গ্রাফ পাওয়া যায়।

## 🧩 ৩. যৌগিক ফাংশন (Composite Function)

দুটি ফাংশন $f$ এবং $g$ এর সমন্বয়ে যে নতুন ফাংশন গঠিত হয়, তাকে যৌগিক ফাংশন বলে। 
*   **$fog(x)$:** $f(g(x))$ ➡️ প্রথমে $g$ ফাংশনটি কাজ করে, পরে $f$ ফাংশনটি কাজ করে। 
*   **$gof(x)$:** $g(f(x))$ ➡️ প্রথমে $f$ ফাংশনটি কাজ করে, পরে $g$ ফাংশনটি কাজ করে।
> 💡 **Exam Tip:** সাধারণত $fog(x) \neq gof(x)$। তবে $fog(x)$ এর ডোমেইন নির্ণয়ের সময় $x$ এর এমন মান বের করতে হবে যা $g$ এর ডোমেইনে আছে এবং $g(x)$ এর মান $f$ এর ডোমেইনে আছে।

## 📈 ৪. পর্যায়বৃত্ত ফাংশন (Periodic Function)

কোনো ফাংশন $f(x)$ এর জন্য যদি এমন একটি ধনাত্মক ধ্রুবক $P$ পাওয়া যায় যাতে $f(x+P) = f(x)$ হয়, তবে $f(x)$ কে পর্যায়বৃত্ত ফাংশন বলে এবং $P$ কে এর **পর্যায় (Period)** বলে।

### 🔹 ত্রিকোণমিতিক ফাংশনের পর্যায় (Periods)
*   $\sin x, \cos x, \sec x, \csc x$ এর পর্যায় = $2\pi$
*   $\tan x, \cot x$ এর পর্যায় = $\pi$

**সাধারণ সূত্র:**
*   $\sin^n(ax+b)$, $\cos^n(ax+b)$, $\sec^n(ax+b)$, $\csc^n(ax+b)$ এর পর্যায় = $\frac{2\pi}{|a|}$ (যেখানে $n$ জোড় বা বিজোড় যেকোনো সংখ্যা)।
*   $\tan^n(ax+b)$, $\cot^n(ax+b)$ এর পর্যায় = $\frac{\pi}{|a|}$।

## 🎨 ৫. ফাংশনের লেখচিত্রের রূপান্তর (Graph Transformations) - **সবচেয়ে গুরুত্বপূর্ণ!**

একটি মূল ফাংশন $y = f(x)$ এর গ্রাফ থেকে কীভাবে অন্যান্য ফাংশনের গ্রাফ আঁকতে হয়, তা নিচে দেওয়া হলো:

### 🔹 স্থানান্তর (Translation)
*   **$y = f(x) + c$:** গ্রাফটি $y$-অক্ষ বরাবর $c$ একক উপরে উঠবে।
*   **$y = f(x) - c$:** গ্রাফটি $y$-অক্ষ বরাবর $c$ একক নিচে নামবে।
*   **$y = f(x + c)$:** গ্রাফটি $x$-অক্ষ বরাবর $c$ একক বামে যাবে।
*   **$y = f(x - c)$:** গ্রাফটি $x$-অক্ষ বরাবর $c$ একক ডানে যাবে।

### 🔹 স্কেলিং বা প্রসারণ (Scaling)
*   **$y = cf(x)$:** $c > 1$ হলে গ্রাফটি $y$-অক্ষ বরাবর প্রসারিত (Stretched) হবে। $0 < c < 1$ হলে গ্রাফটি $y$-অক্ষ বরাবর সংকুচিত (Compressed) হবে।
*   **$y = f(cx)$:** $c > 1$ হলে গ্রাফটি $x$-অক্ষ বরাবর সংকুচিত হবে। $0 < c < 1$ হলে গ্রাফটি $x$-অক্ষ বরাবর প্রসারিত হবে।

### 🔹 প্রতিফলন (Reflection)
*   **$y = -f(x)$:** গ্রাফটি $x$-অক্ষের সাপেক্ষে প্রতিফলিত হবে (উল্টে যাবে)।
*   **$y = f(-x)$:** গ্রাফটি $y$-অক্ষের সাপেক্ষে প্রতিফলিত হবে।
*   **$y = f^{-1}(x)$:** গ্রাফটি $y = x$ রেখার সাপেক্ষে প্রতিফলিত হবে।

### 🔹 পরমমান ফাংশন (Absolute Value)
*   **$y = |f(x)|$:** মূল গ্রাফের $x$-অক্ষের নিচের অংশটুকু $x$-অক্ষের উপরে উঠে আসবে (প্রতিফলিত হবে)। 
*   **$y = f(|x|)$:** মূল গ্রাফের ডান দিকের অংশ অপরিবর্তিত থাকবে এবং $y$-অক্ষের বাম দিকের অংশ মুছে গিয়ে ডান দিকের অংশ $y$-অক্ষের সাপেক্ষে প্রতিফলিত হয়ে বামে বসবে।

## 📊 ৬. মৌলিক ত্রিকোণমিতিক ফাংশনের লেখচিত্র (Basic Trig Graphs)

| ফাংশন | ডোমেইন (Domain) | রেঞ্জ (Range) | পর্যায় (Period) | বৈশিষ্ট্য |
| :--- | :--- | :--- | :--- | :--- |
| **$y = \sin x$** | $\mathbb{R}$ | $[-1, 1]$ | $2\pi$ | মূলবিন্দুগামী, স্পন্দনশীল। |
| **$y = \cos x$** | $\mathbb{R}$ | $[-1, 1]$ | $2\pi$ | $y$-অক্ষকে $(0,1)$ বিন্দুতে ছেদ করে। |
| **$y = \tan x$** | $\mathbb{R} - \{(2n+1)\frac{\pi}{2}\}$ | $\mathbb{R}$ | $\pi$ | $x = \pm\frac{\pi}{2}, \pm\frac{3\pi}{2}$ তে অসীম (Asymptote) হয়। |
| **$y = \cot x$** | $\mathbb{R} - \{n\pi\}$ | $\mathbb{R}$ | $\pi$ | $x = 0, \pm\pi, \pm2\pi$ তে অসীম (Asymptote) হয়। |

## 🎁 ৭. ফর্মুলা ব্যাংক (Quick Revision Table)

| কনসেপ্ট | সূত্র / শর্ত |
| :--- | :--- |
| এক-এক শর্ত | $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$ |
| সার্বিক শর্ত | রেঞ্জ $= $ কো-ডোমেইন |
| বিপরীত ফাংশন | $f(x) = y \iff f^{-1}(y) = x$ |
| বিপরীত ফাংশনের ধর্ম | $f(f^{-1}(x)) = x$ এবং $f^{-1}(f(x)) = x$ |
| $y=f(x)+c$ | $c$ একক উপরে স্থানান্তর |
| $y=f(x+c)$ | $c$ একক বামে স্থানান্তর |
| $y=f(cx)$ | $x$-অক্ষ বরাবর সংকোচন ($c>1$) |
| $y=cf(x)$ | $y$-অক্ষ বরাবর প্রসারণ ($c>1$) |
| $\sin$ এর পর্যায় | $2\pi$ |
| $\tan$ এর পর্যায় | $\pi$ |

> 🧠 **Memory Hack:** 
> * $x$ এর ভেতরে পরিবর্তন হলে ($x \pm c$) গ্রাফ **আড়াআড়িভাবে (Horizontal)** shift করে। (ডানে/বামে)
> * $y$ এর বাইরে পরিবর্তন হলে ($y \pm c$) গ্রাফ **খাড়াভাবে (Vertical)** shift করে। (উপরে/নিচে)
> * $x$ এর সাথে গুণ থাকলে ($cx$) গ্রাফটি $x$-অক্ষ বরাবর সংকুচিত হয়, ভাগ থাকলে ($x/c$) প্রসারিত হয়।
