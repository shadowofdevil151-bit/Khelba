# Chapter 1: বাংলাদেশের বর্তমান পরিবার কাঠামো (Current Family Structure of Bangladesh)

---

## ১. সমাজ ও পরিবার (Society and Family)

**📌 সংজ্ঞা (Definition):**
• **সমাজ (Society):** এমন এক জনসমষ্টিকে বোঝায় যারা একটি সাধারণ ঐতিহ্য, প্রথা, জীবনপ্রণালি বা একটি সাধারণ সংস্কৃতির দ্বারা অনুপ্রাণিত হয়ে একই সাথে বসবাস করে, যার ফলে তাদের একই মনোভাব প্রকাশ পায়।
• **পরিবার (Family):** সমাজবিজ্ঞানী এম এফ নিমকফ (M. F. Nimkoff) এর মতে, "পরিবার মোটামুটিভাবে স্বামী ও স্ত্রী দ্বারা সৃষ্ট একটি সংঘ; এতে সন্তান-সন্ততি থাকতে পারে, আবার নাও থাকতে পারে।"

**🔑 মূল পয়েন্টসমূহ (Key Points):**
• সমাজের প্রাথমিক রূপ হলো পরিবার। পারিবারিক জীবনই সমাজ ও রাষ্ট্রের মূল ভিত্তি।
• পরিবার হলো সমাজের প্রাচীনতম, মৌলিক এবং সর্বাপেক্ষা গুরুত্বপূর্ণ সামাজিক প্রতিষ্ঠান। একে **'সামাজিক চিন্তন বিদ্যালয়'** বলা হয়।
• পরিবার মানুষের জৈবিক প্রয়োজন মেটায় এবং বংশগতি অক্ষুণ্ণ রাখতে সাহায্য করে।
• শিশুর সামাজিক, অর্থনৈতিক, সাংস্কৃতিক ও নৈতিক সকল বিষয়ের প্রাথমিক শিক্ষা পরিবার থেকেই শুরু হয়।

## ২. পরিবারের শ্রেণিবিভাগ (Classification of Family)

**📊 পরিবারের প্রকারভেদ (Comparison Table):**

| শ্রেণিবিভাগের মানদণ্ড (Criteria) | পরিবারের ধরন (Type) | বৈশিষ্ট্য (Characteristics) |
| :--- | :--- | :--- |
| **১. ক্ষমতার মানদণ্ড** | **পিতৃপ্রধান পরিবার (Patriarchal)** | নেতৃত্ব ও কর্তৃত্ব বয়স্ক পুরুষের ওপর ন্যস্ত থাকে। বাংলাদেশে এ ধরনের পরিবারই বেশি দেখা যায়। |
| | **মাতৃপ্রধান পরিবার (Matriarchal)** | নেতৃত্ব দেওয়ার ক্ষমতা বয়স্ক মহিলাদের ওপর ন্যস্ত থাকে। (যেমন: গারো উপজাতি)। |
| **২. স্বামী-স্ত্রীর সংখ্যা** | **একপত্নীক পরিবার (Monogamy)** | একজন পুরুষ ও একজন নারী নিয়ে গঠিত। আধুনিক সভ্য সমাজে সর্বাধিক প্রচলিত। |
| | **বহুপত্নীক পরিবার (Polygamy)** | একজন পুরুষ একাধিক স্ত্রী নিয়ে সংসার গঠন করে। |
| | **বহুপতি পরিবার (Polyandry)** | একজন নারী একাধিক স্বামী নিয়ে সংসার গঠন করে। বর্তমানে প্রায় লোপ পেয়েছে (প্রাচীন মালাবার টোডাদের মাঝে ছিল)। |
| | **গোষ্ঠী পরিবার (Group Marriage)** | দুই বা ততোধিক পুরুষ ও নারীর একত্রে বসবাসের ভিত্তিতে গড়ে ওঠে। আদিম সমাজে এর অস্তিত্ব ছিল। |
| **৩. বাসস্থানের মানদণ্ড** | **পিতৃবাসস্থান পরিবার (Patrilocal)** | বিয়ের পর পাত্রী স্বামীর পৈতৃক গৃহে বসবাস করে। বাংলাদেশে এ ধরনের পরিবার বেশি। |
| | **মাতৃবাসস্থান পরিবার (Matrilocal)** | বিয়ের পর পাত্র স্ত্রীর পৈতৃক গৃহে বসবাস করে। (যেমন: গারো উপজাতি)। |
| | **নব্যবাস পরিবার (Neolocal)** | বিয়ের পর স্বামী-স্ত্রী নতুন বাড়িতে দাম্পত্য জীবন শুরু করে। পাশ্চাত্যে বেশি প্রচলিত, বর্তমানে বাংলাদেশেও বাড়ছে। |
| | **ভ্রমণবাস পরিবার (Duo-local)** | নবদম্পতি কিছুদিন শ্বশুরবাড়ি এবং কিছুদিন বাবার বাড়িতে বসবাস করে। |

| :--- | :--- |
| সমাজের প্রাচীনতম ও মৌলিক প্রতিষ্ঠান কোনটি? | **পরিবার।** |
| পরিবারকে কী বলা হয়? | **সামাজিক চিন্তন বিদ্যালয়।** |
| নিমকফ (Nimkoff) এর মতে পরিবার কী? | **স্বামী ও স্ত্রী দ্বারা সৃষ্ট একটি সংঘ।** |
| বাংলাদেশে কোন ধরনের পরিবার বেশি দেখা যায়? | **পিতৃপ্রধান ও পিতৃবাসস্থান পরিবার।** |
| গারো উপজাতিদের মধ্যে কোন ধরনের পরিবার দেখা যায়? | **মাতৃপ্রধান ও মাতৃবাসস্থান পরিবার।** |
