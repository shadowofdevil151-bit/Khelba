# Chapter ৭: মুদ্রাস্ফীতি (Inflation)

## ১. মুদ্রাস্ফীতির ধারণা (Concept of Inflation)

**📌 সংজ্ঞা (Definition):** যখন সামগ্রিকভাবে পণ্যসামগ্রী ও সেবার দামস্তর ক্রমাগত বৃদ্ধি পেতে থাকে এবং অর্থের মূল্য বা ক্রয়ক্ষমতা ক্রমাগত হ্রাস পেতে থাকে, তখন সেই পরিস্থিতিকে **মুদ্রাস্ফীতি** বলে।

**📊 বিভিন্ন অর্থনীতিবিদের সংজ্ঞা (Definitions by Economists):**

| অর্থনীতিবিদ | সংজ্ঞা |
| :--- | :--- |
| **অধ্যাপক কুলবর্ন** | অধিক পরিমাণ অর্থ অল্প পরিমাণ দ্রব্যসামগ্রীর পিছনে ধাবিত হলে। |
| **কেমারার** | দেশে মোট মুদ্রার যোগান চাহিদার তুলনায় বৃদ্ধি পেয়ে পণ্যসামগ্রীর দাম বৃদ্ধি করে। |
| **অধ্যাপক পিগু** | যখন আয় সৃষ্টিকারী কাজের অপেক্ষা মানুষের আর্থিক আয় অধিক হারে বৃদ্ধি পায়। |
| **অর্থনীতিবিদ ক্রাউথার** | অর্থের মূল্য ক্রমাগত হ্রাস এবং দ্রব্যমূল্য বৃদ্ধি পাওয়া। |
| **অধ্যাপক হ্যারি** | অত্যধিক অর্থের প্রচলনকে মুদ্রাস্ফীতি বলে। |
| **অর্থনীতিবিদ কেইন্স** | যখন দ্রব্যসামগ্রীর তুলনায় কার্যকর চাহিদা অধিক হয়ে পড়ে। |
| **ক্লাসিক্যাল অর্থনীতিবিদ** | অর্থের পরিমাণ বৃদ্ধিই হলো মুদ্রাস্ফীতি। |
| **মনিটেরিস্ট** | অর্থের অতিরিক্ত যোগানই মুদ্রাস্ফীতি। |

**🔑 মুদ্রাস্ফীতির বৈশিষ্ট্য (Characteristics of Inflation):**
• দামস্তর **ক্রমাগত বাড়তে থাকে**।
• অর্থের ক্রয়ক্ষমতা বা মূল্য **কমতে থাকে**।
• অল্প পণ্য কিনতে **অধিক অর্থ** ব্যয় করতে হয়।
• সামগ্রিক যোগানের তুলনায় সামগ্রিক **চাহিদা বেশি** হয়।
• (*মনে রাখতে হবে: কোনো একটি বা কয়েকটি পণ্যের দাম হঠাৎ বেড়ে গেলে তাকে মুদ্রাস্ফীতি বলা যায় না; সামগ্রিক গড় দাম বাড়লেই তাকে মুদ্রাস্ফীতি বলে।*)

## ২. মুদ্রাস্ফীতির হার (Rate of Inflation)

**🔄 নির্ণয়ের সূত্র (Formula):**
মুদ্রাস্ফীতির হার = $\frac{P_1 - P_0}{P_0} \times 100$

*(এখানে, $P_1$ = চলতি বছরের দামস্তর, $P_0$ = ভিত্তি বছরের দামস্তর)*

**🔑 উদাহরণ (Example):**
যদি ২০১৮ সালের দামস্তর $P_0 = 100$ এবং ২০১৯ সালের দামস্তর $P_1 = 110$ হয়, তবে—
মুদ্রাস্ফীতির হার = $\frac{110 - 100}{100} \times 100 = \frac{10}{100} \times 100 = \mathbf{10\%}$

## ৩. মুদ্রাস্ফীতির প্রকারভেদ (Types of Inflation)

**🔄 কারণভিত্তিক শ্রেণিবিভাগ (Flowchart):**
`মুদ্রাস্ফীতি` ➡️ `চাহিদা বৃদ্ধিজনিত (Demand Pull)` + `ব্যয় বৃদ্ধিজনিত (Cost Push)` + `মজুরি বৃদ্ধিজনিত (Wage Push)` + `ঘাটতি ব্যয়জনিত (Deficit Financing)` + `মুদ্রাজনিত (Money)` + `ঋণজনিত (Credit)`

**📊 কারণভিত্তিক প্রকারভেদ (Explanation Table):**

| প্রকারভেদ | সংক্ষিপ্ত ব্যাখ্যা |
| :--- | :--- |
| **চাহিদা বৃদ্ধিজনিত** | সামগ্রিক যোগানের তুলনায় সামগ্রিক চাহিদা বেশি হলে মূল্যস্তরের যে বৃদ্ধি ঘটে। |
| **ব্যয় বৃদ্ধিজনিত** | উৎপাদনের উপকরণ (কাঁচামাল, পরিবহন) এর দাম বৃদ্ধির কারণে উৎপাদন ব্যয় বাড়লে দাম বাড়ে। |
| **মজুরি বৃদ্ধিজনিত** | শ্রমিকদের মজুরি বৃদ্ধির কারণে উৎপাদন ব্যয় ও দ্রব্যমূল্য বৃদ্ধি পায়। |
| **ঘাটতি ব্যয়জনিত** | সরকারের ঘাটতি বাজেট পূরণে অতিরিক্ত অর্থ ছাপালে দ্রব্যমূল্য বৃদ্ধি পায়। |
| **মুদ্রাজনিত** | প্রয়োজনের তুলনায় অতিরিক্ত নোট ছাপিয়ে বাজারে ছাড়লে। |
| **ঋণজনিত** | ব্যাংক ও আর্থিক প্রতিষ্ঠান প্রয়োজনের অতিরিক্ত ঋণ সরবরাহ করলে। |

**📊 গতিভিত্তিক প্রকারভেদ (Speed-based Table):**

| প্রকারভেদ | বৈশিষ্ট্য |
| :--- | :--- |
| **মৃদু মুদ্রাস্ফীতি (Mild)** | দামস্তর খুব ধীরগতিতে বাড়ে। এটি বিনিয়োগ বৃদ্ধির সহায়ক। |
| **পদসঞ্চারী (Walking)** | দামস্তর অপেক্ষাকৃত অধিক হারে বাড়তে থাকে। |
| **ধাবমান (Running)** | দামস্তর খুব দ্রুতগতিতে বৃদ্ধি পায়। |
| **অতিমুদ্রাস্ফীতি (Hyper/Galloping)** | দামস্তর অনিয়ন্ত্রিতভাবে লাফিয়ে লাফিয়ে লাখ লাখ বার বাড়তে থাকে। |

## ৪. মুদ্রাস্ফীতির পরিমাপ (Measures of Inflation)

**🔑 পরিমাপের পদ্ধতি (Methods):**
• GNP Deflator, সূচক সংখ্যা ইত্যাদি। তবে **সূচক সংখ্যা পদ্ধতি** সবচেয়ে সহজ ও বহুল ব্যবহৃত।

**📊 ভোক্তার মূল্য সূচক (Consumer Price Index - CPI):**
ভোক্তার মূল্য সূচকের সাহায্যে মুদ্রাস্ফীতির পরিমাণ নির্ণয় করা যায়। এই সূচক শতকরা যে হারে বৃদ্ধি পায়, তাকেই মুদ্রাস্ফীতির হার হিসেবে ধরা হয়।

**🔑 পরিমাপের উদাহরণ (Example Calculation):**

| ভোগ্য দ্রব্যের নাম | ভিত্তি বছর (Q0) | দাম (P0) | ব্যয় (P0Q0) | চলতি বছর (Q0) | দাম (P1) | ব্যয় (P1Q0) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| চাল | ২৫ | ২০ | ৫০০ | ২৫ | ২৫ | ৬২৫ |
| ডাল | ২০ | ৬০ | ১২০ | ২০ | ৮০ | ১৬০০ |
| তেল | ১০ | ৮০ | ৮০০ | ১০ | ৯০ | ৯০০ |

*(নোট: উপরের সূচক বের করে পূর্বের সূত্রে বসালেই মুদ্রাস্ফীতির হার নির্ণয় করা যাবে)*
