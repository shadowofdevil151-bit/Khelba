# 📚 HSC উচ্চতর গণিত ২য় পত্র - অধ্যায় ৬: কনিক (Conics)

> **অধ্যায়ের সারাংশ:** পরাবৃত্ত, উপবৃত্ত ও অধিবৃত্তের জ্যামিতিক ধর্ম, সমীকরণ, উপকেন্দ্র, নিয়ামক রেখা, উৎকেন্দ্রিকতা এবং পরামিতিক স্থানাঙ্কের সম্পূর্ণ কনসেপ্ট এখানে গোছানোভাবে দেওয়া হলো। এই অধ্যায়টি বোর্ড পরীক্ষার পাশাপাশি বিভিন্ন ভর্তি পরীক্ষার জন্যও অত্যন্ত গুরুত্বপূর্ণ।

## 🎯 ১. কনিকের মূল ধারণা (Basic Concept of Conics)

কোনো সমতলে একটি স্থির বিন্দু (উপকেন্দ্র) এবং একটি নির্দিষ্ট সরলরেখা (নিয়ামক রেখা) থেকে কোনো চলমান বিন্দুর দূরত্বের অনুপাত সর্বদা একটি স্থির ধ্রুবক (উৎকেন্দ্রিকতা, $e$) হলে, চলমান বিন্দুর সঞ্চারপথকে **কনিক (Conic)** বলে।

*   **উপকেন্দ্র (Focus):** স্থির বিন্দুটিকে উপকেন্দ্র বলে (সাধারণত $S$ দ্বারা প্রকাশ করা হয়)।
*   **নিয়ামক রেখা (Directrix):** নির্দিষ্ট সরলরেখাটিকে নিয়ামক রেখা বলে।
*   **উৎকেন্দ্রিকতা (Eccentricity):** স্থির অনুপাতটিকে ($e$) উৎকেন্দ্রিকতা বলে। অর্থাৎ, $e = \frac{SP}{PM}$ (যেখানে $P$ কনিকের উপর কোনো বিন্দু এবং $M$ হলো নিয়ামক রেখার উপর লম্ব পদবিন্দু)।

### 🔄 উৎকেন্দ্রিকতার ($e$) ভিত্তিতে কনিকের প্রকারভেদ:
*   $e = 1$ ➡️ **পরাবৃত্ত (Parabola)**
*   $e < 1$ ➡️ **উপবৃত্ত (Ellipse)**
*   $e > 1$ ➡️ **অধিবৃত্ত (Hyperbola)**

---

## 🧮 ২. সাধারণ সমীকরণ থেকে কনিক শনাক্তকরণ (Identification from General Equation)

দ্বিঘাত সমীকরণের সাধারণ রূপ: $ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0$

| শর্ত (Condition) | কনিকের ধরন (Type of Conic) |
| :--- | :--- |
| $a = b$ এবং $h = 0$ | বৃত্ত (Circle) |
| $ab - h^2 = 0$ | পরাবৃত্ত (Parabola) |
| $ab - h^2 > 0$ | উপবৃত্ত (Ellipse) |
| $ab - h^2 < 0$ | অধিবৃত্ত (Hyperbola) |

---

## 🛤️ ৩. কোণকের ছেদ থেকে কনিক উৎপাদন (Conic Sections from a Cone)

একটি সমবৃত্তভূমিক কোণককে (Right Circular Cone) একটি সমতল দ্বারা ছেদ করলে যে জ্যামিতিক আকৃতি পাওয়া যায়:

*   সমতল যদি ভূমির সমান্তরাল হয় ➡️ **বৃত্ত (Circle)**
*   সমতল যদি অক্ষের সাথে কোণ করে ছেদ করে ➡️ **উপবৃত্ত (Ellipse)**
*   সমতল যদি কোণকের উৎপাদক রেখার সমান্তরাল হয় ➡️ **পরাবৃত্ত (Parabola)**
*   সমতল যদি কোণকের উভয় অংশকে ছেদ করে ➡️ **অধিবৃত্ত (Hyperbola)**

## 📐 ৪. পরাবৃত্ত (Parabola)

**সংজ্ঞা:** যে সঞ্চারপথের প্রতিটি বিন্দু উপকেন্দ্র এবং নিয়ামক রেখা থেকে সমদূরবর্তী, তাকে পরাবৃত্ত বলে। অর্থাৎ, $SP = PM$ এবং $e = 1$।

### 🔹 প্রমিত সমীকরণ ও বৈশিষ্ট্য (Standard Equation & Properties)
**সমীকরণ:** $y^2 = 4ax$ (যেখানে $a > 0$)

| বৈশিষ্ট্য (Property) | মান / সমীকরণ (Value / Equation) |
| :--- | :--- |
| **শীর্ষবিন্দু (Vertex)** | $(0, 0)$ |
| **উপকেন্দ্র (Focus)** | $(a, 0)$ |
| **নিয়ামক রেখা (Directrix)** | $x + a = 0$ (বা $x = -a$) |
| **অক্ষরেখা (Axis)** | $y = 0$ (x-অক্ষ) |
| **উপকেন্দ্রিক লম্বের দৈর্ঘ্য (Latus Rectum)** | $\lvert 4a\rvert$ |
| **উপকেন্দ্রিক লম্বের প্রান্তবিন্দু** | $(a, 2a)$ এবং $(a, -2a)$ |
| **পরামিতিক স্থানাঙ্ক (Parametric Coords)** | $(at^2, 2at)$ |

*   **অন্যান্য রূপ (Other Forms):**
    *   $x^2 = 4ay$ (উপকেন্দ্র: $(0, a)$, নিয়ামক: $y = -a$)
    *   $y^2 = -4ax$ (উপকেন্দ্র: $(-a, 0)$, নিয়ামক: $x = a$)
    *   $x^2 = -4ay$ (উপকেন্দ্র: $(0, -a)$, নিয়ামক: $y = a$)
    *   $(y-\beta)^2 = 4a(x-\alpha)$ (শীর্ষবিন্দু: $(\alpha, \beta)$)

> 💡 **Exam Tip:** পরাবৃত্তের সমীকরণে $x$ এর ঘাত ১ এবং $y$ এর ঘাত ২ হলে অক্ষরেখা $x$-অক্ষের সমান্তরাল হয়। আর $x$ এর ঘাত ২ এবং $y$ এর ঘাত ১ হলে অক্ষরেখা $y$-অক্ষের সমান্তরাল হয়।

## 🥚 ৫. উপবৃত্ত (Ellipse)

**সংজ্ঞা:** যে সঞ্চারপথের প্রতিটি বিন্দু থেকে দুটি নির্দিষ্ট বিন্দুর (উপকেন্দ্র) দূরত্বের সমষ্টি সর্বদা একটি স্থির ধ্রুবক (বৃহৎ অক্ষের দৈর্ঘ্য) হয়, তাকে উপবৃত্ত বলে। অর্থাৎ, $SP + S'P = 2a$ এবং $e < 1$।

### 🔹 প্রমিত সমীকরণ ও বৈশিষ্ট্য ($a > b$)
**সমীকরণ:** $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$

| বৈশিষ্ট্য (Property) | মান / সমীকরণ (Value / Equation) |
| :--- | :--- |
| **কেন্দ্র (Center)** | $(0, 0)$ |
| **বৃহৎ অক্ষের দৈর্ঘ্য (Major Axis)** | $2a$ (x-অক্ষ বরাবর) |
| **ক্ষুদ্র অক্ষের দৈর্ঘ্য (Minor Axis)** | $2b$ (y-অক্ষ বরাবর) |
| **উপকেন্দ্র (Foci)** | $(\pm ae, 0)$ |
| **নিয়ামক রেখা (Directrices)** | $x = \pm \frac{a}{e}$ |
| **উৎকেন্দ্রিকতা (Eccentricity)** | $e = \sqrt{1 - \frac{b^2}{a^2}}$ |
| **উপকেন্দ্রিক লম্ব (Latus Rectum)** | $\frac{2b^2}{a}$ |
| **পরামিতিক স্থানাঙ্ক (Parametric Coords)** | $(a\cos\theta, b\sin\theta)$ |

*   **$a < b$ হলে:** সমীকরণ হবে $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$, তবে বৃহৎ অক্ষ $y$-অক্ষ বরাবর হবে। উপকেন্দ্র হবে $(0, \pm be)$।
*   **মূল সম্পর্ক:** $b^2 = a^2(1 - e^2)$

> 🧠 **Memory Hack:** উপবৃত্তের ক্ষেত্রে "বৃহৎ" সংখ্যাটি সবসময় $a^2$ এর নিচে থাকে (যেমন $25x^2 + 16y^2 = 400 \Rightarrow \frac{x^2}{16} + \frac{y^2}{25} = 1 \Rightarrow a^2=16, b^2=25$। এখানে $b>a$). উৎকেন্দ্রিকতা $e$ সর্বদা ১ এর চেয়ে ছোট হয়।

## 🦋 ৬. অধিবৃত্ত (Hyperbola)

**সংজ্ঞা:** যে সঞ্চারপথের প্রতিটি বিন্দু থেকে দুটি নির্দিষ্ট বিন্দুর (উপকেন্দ্র) দূরত্বের অন্তর সর্বদা একটি স্থির ধ্রুবক (আড় অক্ষের দৈর্ঘ্য) হয়, তাকে অধিবৃত্ত বলে। অর্থাৎ, $|SP - S'P| = 2a$ এবং $e > 1$।

### 🔹 প্রমিত সমীকরণ ও বৈশিষ্ট্য
**সমীকরণ:** $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$

| বৈশিষ্ট্য (Property) | মান / সমীকরণ (Value / Equation) |
| :--- | :--- |
| **কেন্দ্র (Center)** | $(0, 0)$ |
| **আড় অক্ষের দৈর্ঘ্য (Transverse Axis)** | $2a$ (x-অক্ষ বরাবর) |
| **অনুবন্ধী অক্ষের দৈর্ঘ্য (Conjugate Axis)** | $2b$ (y-অক্ষ বরাবর) |
| **উপকেন্দ্র (Foci)** | $(\pm ae, 0)$ |
| **নিয়ামক রেখা (Directrices)** | $x = \pm \frac{a}{e}$ |
| **উৎকেন্দ্রিকতা (Eccentricity)** | $e = \sqrt{1 + \frac{b^2}{a^2}}$ |
| **উপকেন্দ্রিক লম্ব (Latus Rectum)** | $\frac{2b^2}{a}$ |
| **অসীমতট (Asymptotes)** | $y = \pm \frac{b}{a}x$ |
| **পরামিতিক স্থানাঙ্ক (Parametric Coords)** | $(a\sec\theta, b\tan\theta)$ |

*   **অনুবন্ধী অধিবৃত্ত (Conjugate Hyperbola):** $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ এর অনুবন্ধী অধিবৃত্তের সমীকরণ $\frac{y^2}{b^2} - \frac{x^2}{a^2} = 1$।
*   **মূল সম্পর্ক:** $b^2 = a^2(e^2 - 1)$

> 🧠 **Memory Hack:** অধিবৃত্তের ক্ষেত্রে $a^2$ এবং $b^2$ এর মাঝে মাইনাস (-) চিহ্ন থাকে। উৎকেন্দ্রিকতা $e$ সর্বদা ১ এর চেয়ে বড় হয়। অসীমতটের সমীকরণ মনে রাখার সহজ নিয়ম: সমীকরণের ডান পাশের ১ কে ০ ধরলে পাওয়া যায় $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0 \Rightarrow y = \pm \frac{b}{a}x$।

## 🎯 ৭. স্পর্শক হওয়ার শর্ত (Condition of Tangency)

$y = mx + c$ সরলরেখাটি বিভিন্ন কনিককে স্পর্শ করবে যদি:

| কনিক (Conic) | সমীকরণ (Equation) | স্পর্শক হওয়ার শর্ত (Condition) |
| :--- | :--- | :--- |
| **পরাবৃত্ত** | $y^2 = 4ax$ | $c = \frac{a}{m}$ |
| **উপবৃত্ত** | $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ | $c^2 = a^2m^2 + b^2$ |
| **অধিবৃত্ত** | $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ | $c^2 = a^2m^2 - b^2$ |

> 💡 **Exam Tip:** উপবৃত্তের ক্ষেত্রে $c^2 = a^2m^2 + b^2$ শর্তটি মনে রাখতে হবে (প্লাস চিহ্ন)। আর অধিবৃত্তের ক্ষেত্রে $c^2 = a^2m^2 - b^2$ শর্তটি মনে রাখতে হবে (মাইনাস চিহ্ন)।

> 🧠 **Memory Hack:** 
> *   **উপবৃত্ত (Ellipse):** যোগ (+) চিহ্ন, $e < 1$, স্পর্শক শর্ত $c^2 = a^2m^2 + b^2$।
> *   **অধিবৃত্ত (Hyperbola):** বিয়োগ (-) চিহ্ন, $e > 1$, স্পর্শক শর্ত $c^2 = a^2m^2 - b^2$।
> *   **পরাবৃত্ত (Parabola):** $e = 1$, স্পর্শক শর্ত $c = a/m$।
